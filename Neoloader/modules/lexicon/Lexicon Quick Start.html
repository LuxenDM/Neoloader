Lexicon Quick Start

Lexicon is a dictionary-style translation library. It replaces Babel as Neoloader’s standard translation library.

For most plugins, you only need two functions:

  • register() — load your translation files.

  • fetch() — retrieve translated strings.

Everything else is optional.

Step 1: Require Lexicon

local lexicon
 local lang_page
 
 local lexicon_ready = function()
 
     lexicon = lib.get_class(
         "lexicon",
         "0"
     )
 
 end
 
 lib.require({
     {
         name = "lexicon",
         version = "0",
     },
 }, lexicon_ready)

Step 2: Create a translation file

Example:

[lexicon]
 code=en
 lang=English
 
 1=Open
 2=Close
 3=Settings
 4=Hello World!

You can create additional files for other languages:

lang/
     en.ini
     es.ini
     fr.ini
     de.ini

Step 3: Register your translations

After Lexicon has loaded:

lang_page = lexicon.register(
     "myplugin",
     "1.0.0",
     plugin_path .. "lang/en.ini"
 )
 
 lexicon.register(
     "myplugin",
     "1.0.0",
     plugin_path .. "lang/es.ini"
 )
 
 lexicon.register(
     "myplugin",
     "1.0.0",
     plugin_path .. "lang/fr.ini"
 )

Register every language your plugin provides.

Only the first call’s return value needs to be saved.

Step 4: Create a helper

Almost every plugin should make a helper function:

local lstr = function(id, default)
 
     if not lexicon or not lang_page then
         return default
     end
 
     return lexicon.fetch(
         lang_page,
         id,
         default
     )
 
 end

Step 5: Use it

Instead of writing:

title = "Settings"

write:

title = lstr(
     3,
     "Settings"
 )

If the user’s language is available, they’ll see the translated version.

Otherwise, they’ll see:

Settings

Translation Keys

Numeric keys are recommended:

1=Open
 2=Close
 3=Settings

Then:

lstr(1, "Open")
 lstr(2, "Close")
 lstr(3, "Settings")

Missing Translations

Always provide a default string:

lstr(7, "Retry")

If the translation doesn’t exist, the default is used automatically.

Your plugin will continue working even if:

  • Lexicon isn’t installed yet.

  • The user selects an unsupported language.

  • A translation file is missing.

  • A particular string hasn’t been translated.

Complete Example

local lexicon
 local lang_page
 
 local lstr = function(id, default)
 
     if not lexicon or not lang_page then
         return default
     end
 
     return lexicon.fetch(
         lang_page,
         id,
         default
     )
 
 end
 
 local lexicon_ready = function()
 
     lexicon = lib.get_class(
         "lexicon",
         "0"
     )
 
     lang_page = lexicon.register(
         "myplugin",
         "1.0.0",
         plugin_path .. "lang/en.ini"
     )
 
     lexicon.register(
         "myplugin",
         "1.0.0",
         plugin_path .. "lang/es.ini"
     )
 
 end
 
 lib.require({
     {
         name = "lexicon",
         version = "0",
     },
 }, lexicon_ready)
 
 local button = iup.stationbutton{
     title = lstr(
         1,
         "Open"
     ),
 }

That’s It

For most plugins, these are the only functions you’ll ever use:

lexicon.register()
 lexicon.fetch()

Everything else in the Lexicon API exists to support advanced localization features, custom interfaces, language selection, and transliteration.
